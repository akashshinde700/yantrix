# Form fields ka lookup

[Video aur step-by-step guide](README.md) · Panel ya label ke liye Ctrl+F / Cmd+F karein. Neeche form ke **asli English labels** diye hain taaki screen se match ho. Har repeated row ko sirf ek baar dikhaya hai. Ye field names/hints hain, kisi user ke bhare hue values nahi. Dashboard, inbox aur list-only controls ke liye main guide dekhein.

## Courses / Basics

**Course card & identity**

- Course name — Shown as the card title and in the page heading.
- Level — e.g. Beginner → Advanced
- URL slug — Course page: /courses/full-stack-development. Duplicate slugs get a -2 suffix automatically.
- Icon — Shown on the card when no cover image is uploaded.
- Badge — Optional ribbon on the card, e.g. “Most popular”.
- Short description — Two lines on the card; also used in search results.
- Tagline — One confident line under the course page headline.
- Who it is for (headline line) — Shown with a people icon under the headline, e.g. freshers & working professionals.
- Who should attend — heading — Leave empty to use the default “Is this course right for you?”.
- Who should attend — bullets — One persona per line. This powers its own “Who should attend?” section on the course page.
- “What do we offer” heading — Optional heading for the benefit cards. Leave empty for “What makes … different”.

**Cover image**

- Upload / replace cover photo, remove, ya image path paste karein.
- Image alt text — Describe the image for accessibility and image search.

**Fee, batch & mode**

- Fee — e.g. ₹45,000, or “On request”.
- Duration
- Fee note — Small print under the price, e.g. instalments.
- Batch note — Shown in the price card and quick facts.
- Seats note
- Instructor / mentor line
- Language
- Modes — Common values: Online, Offline. One per row.
- Highlight chips — Three short chips on the card (syllabus keywords).
- Headline stats — Small chips under the course page headline.
- Announcement strip — The strip above the course page, e.g. “Admissions open — limited seats”. Leave empty to hide it.
- Next batch start date — YYYY-MM-DD. With a date set, the strip shows a live countdown.
- Published — Off rakhne se course public website par hidden rahega.

## Trainers / Add mentor

**Mentors**

- Profile photo — A square, well-lit head-and-shoulders photo works best. It is resized automatically.
- Full name
- Current designation
- Company / institution — Shown under the name on the mentor card, like “IIT Bombay” or “GNS Pvt Ltd”.
- Specialisation — Short label shown on the card and used by the filter chips, e.g. Data Science, AWS DevOps, Cybersecurity.
- Total experience (years) — Shown as a badge. Set 0 to hide.
- LinkedIn URL (optional)
- Short introduction — Two or three sentences in the trainer's voice.
- Professional experience — One role per line, most recent first.
- Educational background — One qualification or certification per line.
- Technical skills — One skill per line — shown as chips.
- Industry experience — Industries / domains the trainer has worked in, one per line.
